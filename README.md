# Bank Account Management System

This Python program simulates a simple bank account management system. It allows the user to deposit money, withdraw money, check the balance, and view account details.

## Features

* Creates a bank account with account holder details
* Accepts an initial account balance
* Deposits money into the account
* Withdraws money from the account
* Checks the current balance
* Displays account details
* Prevents withdrawal when the balance is insufficient
* Uses a menu-driven system

## Technology Used

* Python

## Concepts Used

* Variables
* User input
* `while` loop
* `if-elif-else`
* Arithmetic operations
* Menu-driven programming
* Conditional validation
